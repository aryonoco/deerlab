# deerlab

My personal homelab. Two Debian 13 VPSs configured entirely by Ansible: an edge
host running Caddy, a services host running each application as a rootless
Podman Quadlet under its own account, joined by kernel WireGuard.

This is my own infrastructure rather than a project for general use. I am not
looking for contributions and there is no support.
